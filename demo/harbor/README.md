# Harbor Lights

Original AI-assisted animated scene created for Accord using Google Veo and Google Cloud Text-to-Speech, with original script, editing and synthesized sound. No third-party film excerpt.

`master.mp4` is the original 16-second film. `clean-tracks.json` contains the known-answer controls. `test-tracks.json` deliberately introduces review defects; these are testing inputs, not errors in a real released translation. `reviewed-story-notes.json` is the explicit human-reviewed reference, not unedited extraction output.
